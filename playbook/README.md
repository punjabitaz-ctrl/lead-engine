# Playbook: from reply to paid project

Templates for the back half of the funnel. Square brackets are yours to fill. Nothing here is legal advice: have a New Jersey attorney review
`agreement-template.md` before the first signature.

| File | Use it when |
|---|---|
| `offer-and-pricing.md` | deciding what is sold, what is not, and the rules (capacity, remote first, in-person threshold) |
| `call-script.md` | a practice replies or you call (remote first) |
| `objection-handling.md` | "we already have a site", "send me info", "too busy", "how much" |
| `followup-emails.md` | replies you send after a conversation; every send is approved by you first |
| `proposal-template.md` | after the call: one page, sent same day |
| `agreement-template.md` | the signature step, before any work |
| `privacy-policy-template.md` | a client needs a privacy and data-retention policy; a draft for their attorney to review |
| `intake-form.md` | after payment: what you need from the practice to start the 72-hour clock |
| `delivery-checklist.md` | building and handing over each site |

Track every deal with `leadengine campaign deal add|move` and read `leadengine campaign pipeline <name>`.
